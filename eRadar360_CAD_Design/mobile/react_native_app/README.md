# eRadar360_CAD — React Native App

> 360-degree driver awareness radar

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | React Native 0.74 + Expo 51 |
| Navigation | React Navigation 6 (Bottom Tabs) |
| Styling | NativeWind (Tailwind CSS for RN) |
| HTTP | Axios |
| Testing | Jest + React Testing Library |
| Language | TypeScript (strict) |

## Platforms

| Platform | Command |
|---|---|
| iOS | `npm run ios` |
| Android | `npm run android` |
| Web | `npm run web` |

## Development

```bash
cd mobile-rn
npm install
npm start
npm test
```
