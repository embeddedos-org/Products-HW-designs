# eMedical CAD Design

> EmbeddedOS medical hardware portfolio covering diagnostic equipment, surgical devices, patient care systems, and laboratory equipment — all designed to run the eOS medical-grade embedded stack.

## Product Lines

| Product | Category | Key Standard | Status |
|---|---|---|---|
| diagnostic_equipment | ECG, EEG, Ultrasound, Patient monitors | IEC 60601-1 | Design |
| surgical_devices | Surgical robots, Electrosurgical, Navigation | IEC 60601-2 | Design |
| patient_care | Infusion pumps, Ventilators, Rehab robots | ISO 13485 | Design |
| laboratory_equipment | PCR, Centrifuges, DNA sequencers | ISO 15189 | Design |
