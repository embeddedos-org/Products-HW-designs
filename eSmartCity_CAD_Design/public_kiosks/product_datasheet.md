# Public Information Kiosks — Product Datasheet
> **Revision:** v1.0 | **Date:** 2026-08-08 | **Status:** Design Phase

## Product Overview
Outdoor interactive kiosk providing wayfinding, transit information and emergency messaging with accessibility compliance built into the hardware rather than retrofitted. Sunlight-readable display and tactile audio navigation are specified from the outset because both drive enclosure and thermal design.

## Electrical Specifications — eKSK-900
| Parameter | Specification |
|---|---|
| **Processor** | NXP i.MX 8M Plus quad Cortex-A53 |
| **Display** | 32-inch 2500 nit sunlight-readable, capacitive touch |
| **Accessibility** | EN 301 549 conformant: audio navigation, tactile keypad, induction loop |
| **Connectivity** | Wi-Fi 6 public hotspot, 5G backhaul, wired fallback |
| **Emergency mode** | Priority override for civil alert messaging |
| **Vandal resistance** | IK10 impact rating, anti-graffiti coating |
| **Environment** | IP65, -20degC to +50degC with active thermal management |

## PCB Specifications
| Parameter | Value |
|---|---|
| **Layers** | 10 |
| **Dimensions** | 220mm x 170mm |
| **IPC Class** | Class 2 |
| **Finish** | ENIG, conformal coated |
