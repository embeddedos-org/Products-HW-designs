# Nanotechnology Instrumentation — Product Datasheet
> **Revision:** v1.0 | **Date:** 2026-08-08 | **Status:** Research

## Product Overview
Scanning probe microscope controller driving piezo nanopositioners and closing the feedback loop on tip deflection at 200 kHz. Sub-nanometre positioning is limited by drive amplifier noise, so the high-voltage stage carries the tightest noise budget in the design.

## Electrical Specifications — eNANO-600
| Parameter | Specification |
|---|---|
| **Positioning** | 3-axis piezo, 100um range, 0.2 nm resolution |
| **Drive amplifier** | 220V high-voltage, <8 uV/rtHz output noise |
| **Feedback rate** | 200 kHz tip deflection control loop |
| **Detection** | Optical lever with quadrant photodiode, 24-bit acquisition |
| **Scan modes** | Contact, tapping, non-contact and force spectroscopy |
| **Drift** | <0.05 nm/min thermal drift after settling |
| **Environment** | Vibration-isolated, optional vacuum compatibility |
